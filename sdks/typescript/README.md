# OpenDataGraph TypeScript Enforcement SDK

`OpenDataGraphPEP` provides fail-closed AuthZEN evaluation, required-obligation handlers, and receipt-linked enforcement reporting for Node.js 20 and modern runtimes with `fetch`.

Run `npm install` and `npm run build` in this directory to produce ESM JavaScript and declarations under `dist`.

Never send prompts, model responses, credentials, or customer content in enforcement metadata.
